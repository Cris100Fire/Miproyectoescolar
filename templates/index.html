¿Qué es un logaritmo?

El logaritmo es la operación inversa a la potenciación.
Ejemplo: Si 2^3 = 8, entonces log2(8) = 3.

Propiedades de los Logaritmos

1. loga(N) = b, entonces N = ab

Si el logaritmo de un número es igual a un valor, entonces el número es la base elevada a ese valor.
Ejemplo: log2(8) = 3 → 23 = 8

2. loga(a) = 1

El logaritmo de un número en su misma base siempre es 1.
Ejemplo: log5(5) = 1

3. loga(bc) = c · loga(b)

El exponente puede salir del logaritmo como un factor multiplicativo.
Ejemplo: log2(82) = 2 × log2(8) = 2 × 3 = 6

4. loga(ac) = c

Si tienes la base elevada a un exponente dentro del logaritmo, simplemente el resultado es el exponente.
Ejemplo: log3(34) = 4

5. logb(c / d) = logb(c) - logb(d)

El logaritmo de un cociente es igual a la resta de los logaritmos del numerador y del denominador.
Ejemplo: log5(25 / 5) = log5(25) - log5(5) = 2 - 1 = 1

6. logb(c × d) = logb(c) + logb(d)

El logaritmo de un producto es igual a la suma de los logaritmos de cada factor.
Ejemplo: log2(4 × 8) = log2(4) + log2(8) = 2 + 3 = 5

7. logc⁽ᵇ⁾(a) = (1/b) logc(a).

Cambiando de base, puedes reescribir un logaritmo utilizando una fracción.
Ejemplo: log2⁽³⁾(8) = (1/3) × log2(8) = (1/3) × 3 = 1

8. loga(s) × logs(r) × logr(c) = loga(c)

La multiplicación encadenada de logaritmos de esta forma simplifica a un único logaritmo.
Ejemplo: log2(4) × log4(16) × log16(256) = log2(256) = 8

9. cologa(b) = loga(1 / b)

El cologaritmo de un número es el logaritmo del inverso de ese número.
Ejemplo: colog10(100) = log10(1/100) = -2

10. antiloga(b) = ab

El antilogaritmo es simplemente elevar la base al número dado.
Ejemplo: antilog2(3) = 23 = 8
